# 方寸-围城 / INCH · SIEGE —— 设计与实现规格

> 方寸之内，退无可退。

本文档用于在另一个工作区从零复现《方寸-围城》。所有数值均为**建议实现值**，不是参考值——照抄即可得到一致手感。凡本文档未提及的视觉细节，以第 3 节 Design Token 为准，不得自由发挥。

**项目定位（2026-11）**：本项目只有一款作品——《围城》的波次射击，三个模式（经典围城 / 单人围城 / 快速围城）。不再有合集入口，也没有其他待做作品：打开 `index.html` 直接进入围城的初始界面。此前试作过的九款储备（落差、悬廊、空巷、深井、断桥、哑火、尾灯、逆流、引信）连同代码与规格一并删除，只留下本文件里仍被《围城》用到的部分。

1. **两个字**，不加形容词

> 只此两条。名字不需要预示失败方式，也不需要概括玩法——名字只要立得住，剩下的由规格来说。

这四条是围城的底线，任何改动都不得违反：

| # | 公理 | 含义 |
|---|---|---|

## 2. 技术形态（硬约束）

### 2.1 文件

- 单个 `.html`，内联 `<style>` 与 `<script>`
- **体积不设上限**：单文件是为了"双击就能玩"，不是为了字节数。该写清楚的注释照写，别为了省几 KB 把"为什么这样做"删掉
- 编码 UTF-8，`<meta charset="UTF-8">`
- 视口：`width=device-width, initial-scale=1.0`
- 只支持桌面浏览器（Chrome / Edge 最新版），**不做移动端适配、不做触屏**

### 2.2 画布

```js
DPR = Math.min(window.devicePixelRatio || 1, 2)
canvas.width  = Math.floor(W * DPR)
canvas.height = Math.floor(H * DPR)
canvas.style.width  = W + "px"
canvas.style.height = H + "px"
ctx.setTransform(DPR, 0, 0, DPR, 0, 0)
```

- `W = innerWidth`，`H = innerHeight`，每次 `resize` 重算并重新 `setTransform`
- `html, body { overflow: hidden; margin: 0; }`
- 游戏区域 = 整个视口，不存在"画布外"

### 2.3 主循环

```js
dt = Math.min((now - last) / 1000, 0.05)
```

- 单 `requestAnimationFrame` 循环，`dt` 上限 0.05s（切标签页回来不会瞬移）
- 所有运动以 `dt` 为单位（px/s、s/次），**不得写死每帧增量**
- 状态机：`"menu" | "playing" | "paused" | "over"`，单一枚举变量
- `paused` 与 `over` 状态下不执行 `update()`，但**继续执行 `render()`**

### 2.4 键位（本项目统一，不得改动）

| 键 | 作用 | 备注 |
|---|---|---|
| `WASD` / 方向键 | 移动 | 对角线速度需归一化 |
| 鼠标移动 | 瞄准 / 定位 | 无瞄准概念的游戏忽略此项 |
| 鼠标左键 | 对局：射击；界面：确认 | 对局按下即触发；界面按下只高亮，抬起才执行 |
| `Shift` | 冲刺（统一命名：冲刺） | 冷却 1.25s，持续 0.15s，期间无敌 |
| `Esc` | 暂停 / 继续 | 切换 `playing` ⇄ `paused` |
| `Esc` | 返回上一级 | `over` 回首页；`equip` / `mode` 子页回首页 |
| `R` | 重开 | 仅在 `over` 状态有效，沿用本局装备与模式 |
| `M` | 切换射击模式 | 对局/暂停中有效；每把枪各记一份，AL-15 只有连发，按了没反应 |
| `Space` / `Enter` | 前进 | 首页 → 模式页；模式页 → 开局 |

- 全局 `cursor: none`，鼠标指针由 Canvas 绘制（见 3.6）
- 初始界面里的所有操作都走鼠标点击：不留键盘焦点环，也不做 Tab 导航
- `window.addEventListener("blur", ...)` 时清空按键表与鼠标按下状态，防止卡键
- 禁用 `Space`、方向键的默认滚动行为

### 3.2 背景合成（本项目共用）

```
径向渐变：中心 (W/2, H/2)，内半径 60，外半径 max(W,H)*0.78
  0%   #101728
  55%  #0a0e18
  100% #05070c

网格：步长 64px，线宽 1px，颜色 rgba(90,130,190,0.075)
  坐标取整 + 0.5 防止模糊

暗角：径向渐变，内半径 min(W,H)*0.42，外半径 max(W,H)*0.85
  0%   rgba(0,0,0,0)
  100% rgba(0,0,0,0.55)
```

网格**静止**：不随时间漂移，也不跟相机走，锚点取屏幕中心（`ox = (W/2) % 64`、`oy = (H/2) % 64`）。
背景层不制造运动，运动只属于实体——一层持续蠕动的网格会跟敌人、子弹抢注意力。

### 3.4 实体描边与光

- 所有实体（玩家、敌人、道具）均为**圆形**，使用径向渐变填充 + 2px 描边
- 径向渐变的高光点位于左上 `(-r*0.3, -r*0.35)`，模拟单一光源
- **不使用 `shadowBlur`**（性能不可控）。需要"发光"感时，用比本体大 6px 的半透明同色圆垫底，透明度 0.14–0.16
- 所有实体在地面有椭圆或圆形阴影：`rgba(0,0,0,0.4–0.45)`，向下偏移 4–5px
- **敌人也是眼睛球**：一对白眼球，一道斜着压到眼下的眉，一颗盯住前方的瞳——一副冲你来的怒相。眉画在眼球里，不另起一条线。见 UI.md 5.4
- **玩家是眼睛球**：一对竖椭圆黑眼 + 正中一颗白眼球，画在本体最上层（颜色不换，只是谁包着谁）。白眼球随视线偏到眼眶边缘，黑边只剩背侧一片弯月。**没有嘴**——表情全在眼形上：平静 / 血量 ≤ 35% 时内眼角上挑 / 开火时内上角被斜切一刀（瞪人）。参数见 UI.md 5.3.2

### 3.7 动效参数

| 效果 | 参数 |
|---|---|
| 屏震 | 幅度上限 16，衰减 26/s，实际位移 = `rand(-shake, shake) * 0.3`，作用于整个场景的 `translate` |
| 粒子 | 方形（`fillRect`），边长 1.5–3.6px，寿命 0.25–0.7s，速度阻尼 `pow(0.02, dt)`，透明度 = `life / maxLife` |
| 枪口火焰 | 存活 0.07s，半径 `8 + progress*60`，色 `rgba(255,235,150,0.85)` |

## 4. 手感规范

### 4.1 打击感四件套

任何一次"命中"必须同时触发以下四项，缺一不可：

1. **白闪**——被击中对象 0.12s 变白
2. **击退**——给目标施加 0.012 倍弹道速度的位移冲量，随时间指数衰减
3. **火花**——命中点爆出 5 个同色系粒子，初速 150 左右
4. **微震**——`shake += 1.6`，上限 9（击杀时 `+= 4`，上限 14）

### 4.2 输入宽容

- **开火**：按下即发射，不等待抬起；冷却按装备固定间隔（AL-11 0.25s / AL-15 0.052s / AL-18 0.15s）
- **冲刺**：无敌帧覆盖整个 0.15s 位移过程，且冲刺中不受伤、不减速
- **暂停与重开**：从任何状态都能在 1 帧内响应，不等待动画结束
- **贴脸命中**：子弹从玩家边缘 6px 处生成，分 3 个子步判断敌人——贴到身上也能打死

### 4.3 难度曲线通则

- 敌人**不做数值成长**：血量与速度从第一关到第 N 关完全一致，难度只来自数量与敌人构成
- 因此"变难"不能靠加数值，只能靠加数量、加远程、加同屏密度——这是有意的选择，别偷偷把成长加回来
- 经典围城每波数量 `4 + floor(wave × 2.2)`，波间 2.0s，首波延迟 0.9s
- 单人围城每关数量 `6 + level × 2`，每 1.6s 涌入 1–3 个，关间 1.2s，首关延迟 1.0s
- **快速围城**：第 N 关的内容 = 单人围城第 `5N` 关（数量、构成、小队全一样），但刷新间隔一律 ÷5——每 0.32s 涌入 1–3 个，关间 0.24s，首关延迟 0.2s。所以单人第 5 关就是快速第 1 关
- 场上敌人上限 46（性能与可玩性共同决定）

### 4.4 死亡与重开

- 死亡瞬间：60 颗红色粒子 + 20 颗白色粒子，`shake = 22`，立即切 `over` 状态
- 不播放死亡动画，不做慢动作，不做黑屏过渡
- 结算屏出现到可重开之间**无延迟**
- 中途放弃走暂停屏的「退出本局」：直接回首页，不记分、不写结算屏——没打完的一局不算成绩

## 5. 围城规格

俯视角射击。开局选一件装备、一个模式，一局打到死。"围城"的意思是**你被围住**，不是你去攻城。

### 5.1 三个模式

| | 经典围城 `SIEGE` | 单人围城 `SAFEHOUSE` |
|---|---|---|
| 地图 | 等于一屏，无墙 | 一屏半，有墙 |
| 视野 | 全图（没有相机这回事） | 一屏，即地图的 2/3 |
| 敌人来源 | 屏幕外四边的随机点 | 三个门洞（上、左、右） |
| 推进 | 波次无限，一波清完来下一波 | 关卡，清空一关进下一关 |
| 结算明细 | `坚持 N 波` | `到达 N 关` |
| 设计意图 | 场地空、节奏快，考验走位 | 场地有掩体、有死角，考验读图 |

三个模式共用同一套玩家、装备、敌人与打击感，只有地图、视野、推进方式与节奏不同。
快速围城 = 单人围城的压缩版：同一张安全屋、同一套关卡内容，只是把节奏压到 1/5，用更短的时间打同样的量。

### 5.2 装备

三件激光武器，同一个家族的三个口径。名字就是型号，卡片上只显示型号。

| 装备 | 伤害 | 间隔 | 散布 | 弹速 | 射程 | 弹径 | 后坐 |
|---|---|---|---|---|---|---|---|
| AL-08 `LASER RIFLE` | 25 | 0.20s（三连发） | ±0.0227rad（1.3°） | 950px/s | 800px | 3.2 | 1.6 |
| AL-10 `LASER PISTOL` | 10 | 0.25s | ±0.0227rad（1.3°） | 700px/s | 600px | 2.8 | 1.2 |
| AL-11 `LASER PISTOL` | 52 | 0.25s | ±0.0157rad（0.9°） | 1000px/s | 800px | 2.8 | 0.8 |
| AL-15 `LASER SMG` | 13 | 0.052s | ±0.0611rad（3.5°） | 1500px/s | 800px | 2.8 | 1.6 |
| AL-18 `LASER RIFLE` | 32 | 0.15s | ±0.0200rad（1.1°） | 1100px/s | 935px | 3.2 | 1.4 |

五把枪的理论 DPS 是 161 / 40 / 208 / 250 / 213。AL-08 是敌人那把枪的原版——只有三连发，3 发在 0.4s 内出完、两轮之间 0.2s，按住会自动接下一轮。AL-10 是陪练档（DPS 40），它存在的意义是给士兵一把「和玩家同源但更弱」的枪。
AL-15 最高，代价是散布最大、单发最轻，靠贴脸才能吃满；AL-11 单发最重、要压准；AL-18 居中，点射压制。

**射击模式**（`M` 切换，每把枪各自记住，重开一局也保持；**默认都是连发**——老版本一直连发，别让人一进对局按住左键没反应）。
循环顺序：AL-11 `连发 → 单发`，AL-18 `连发 → 单发 → 三连发`。模式自带散布，收得越紧越吃准头：

| 枪 | 模式 | 散布 | 说明 |
|---|---|---|---|
| AL-11 | 单发 | 0.5° | 一次按下打一发，必须松开再按 |
| AL-11 | 连发 | 0.9° | 按住就射，间隔 0.25s |
| AL-15 | 连发 | 3.5° | 只有一种模式，按 M 无反应 |
| AL-18 | 单发 | 0.7° | 一次一发 |
| AL-18 | 三连发 | 0.95° | 一次按下打 3 发，组内间隔 `0.4/3 ≈ 0.133s`，末发落在 0.27s——0.4s 是全组的上限 |
| AL-18 | 连发 | 1.1° | 按住就射，间隔 0.15s |

单发与三连发都要**松开再按**才放下一组：按住不放不会自动连打，这是"单发"与"连发"唯一的区别。

三连发的两条硬规则（都踩过坑）：

1. **上一组没打完，新的按键直接丢弃**——否则新组会顶掉旧组的余量，5 发子弹混在一起喷出去。
2. **冷却从最后一发起算**（0.15s），不是从第一发算。从第一发算的话冷却在组内就跑完了，下一组立刻接上，三连发会变成每秒十发的机枪。

实测：连点每秒 10 下，1 秒内 6 发（旧版 10 发）；按住 1 秒只出 1 组 3 发；持续 5 秒的 DPS 约 211，与连发模式的 192–213 同一档。

- 子弹寿命 = `射程 / 弹速`（不再写死 0.85s），命中或撞墙即消失，飞行中留下 20px 拖尾
- 每帧把这一帧的位移拆成 3 个子步，每个子步都判墙与敌人——贴脸不会漏判，高速不会穿人
- 开火后坐：`recoil = kick × 2.2`，以 22/s 衰减，枪管随之后缩 2–4px

|---|---|

### 5.4 敌人

| 敌人 | 半径 | HP | 速度 | 接触伤害 | 分值 | 颜色 | 出场 |
|---|---|---|---|---|---|---|---|
| 追击兵 `chaser` | 15 | 95 | 100 | 15 | 10 | `#ff5b5b` | 全程 |
| 快速兵 `fast` | 10 | 50 | 190 | 10 | 15 | `#ffd166` | 第 3 关 / 第 3 波起 |
| 重装兵 `tank` | 26 | 160 | 58 | 25 | 30 | `#a06bff` | 第 4 关 / 第 4 波起 |
| 炮手 `gunner` | 16 | 110 | 72 | 5（弹 18） | 22 | `#ff8a3d` | 第 7 关起（仅单人围城） |
| 士兵 `soldier` | 14 | 80 | 105 | 6（持枪） | 25 | `#ff4d8d` | 第 10 关起，成队出现 |

**寻路**：以玩家为源点跑一张距离场（BFS，48px 一格，格子按敌人半径留 16px 余量并标记阻挡），敌人取步数更小的邻格中心作为去向，叠加正弦横摆（振幅系数 0.28）与同伴分离力（重叠深度 `×(r1+r2-d)×2.2`）。

- 直线能走过去时，距离场给出的方向与直追完全一致，看不出在"寻路"
- 被墙挡住时会沿走廊绕到屏风另一侧，**不会在墙角原地打转**——这正是不能用"贴墙切向 + 就近一端"这类局部规则的原因：墙是左右对称的，局部规则在墙正中会左右翻面，敌人会永远停在玩家正上方抖动
- 距离场只在玩家跨到新格子时重算一次，其余帧复用

**炮手（远程）**：只在距玩家 240–420 的带里横移——远了靠过去（走 BFS 方向，会绕墙）、近了背对退开，带内只改角度不改距离。
蓄能 0.75s（其间速度降到 25%，是留给玩家反打的窗口）、0.55s 起瞄准线定死、再 0.2s 发一颗 430px/s 的弹，冷却 2.0–2.6s 随机（避免几只齐射）。
**看不见就不打**：只在自己位于视口内、且与玩家之间没有墙时才开火。同屏上限 3 只；第 7 关起权重 16%（重装 8% / 快速 18% / 追击 58%），经典围城不出现。

**接触**：命中后玩家无敌 0.55s、敌人攻击冷却 0.7s、双方互相击退 320。每帧把重叠推开（只推敌人），避免敌人嵌进玩家身体。

**敌军小队（三方混战）**

士兵是第三方：打玩家、也打围城敌人；围城敌人同样会打他们（接触伤害 ×0.6 护甲）。
**同阵营互不打**：士兵之间不会互相开火，围城敌人之间也不会。选目标时先按阵营过滤，再比距离（玩家的距离 ×0.75，稍微优先）。
三人一队，**1 人持 AL-08、2 人持 AL-10**；AL-08 是火力手，占全队 64% 的输出。

- **发现**：看得见 500px、隔墙 150px；士兵的眼更近，只有 380px。没发现的敌人以 **70% 速度搜索前进**、不攻击。
- **掩体**：每个士兵每 1.2s 重算一次射击位——绕目标撒 12 个点，优先「打得到 + 贴墙」，再优先「离自己近」。
- **掩护推进**：同时只有一个在换位；移动中举枪 0.35s 才能开火，站定的掩护位没有这个延迟。
- **开火**：一轮 7 发（3+3+1，组内 0.133s、组间 0.2s），打完冷却 0.5s。**不预判**——瞄你当前位置，横向跑就能躲。
- **后撤**：只有**围城敌人**在 220px 内 ≥5 只时才触发（玩家贴脸不会让它们跑）。一次退 300px、1.3s，全员移动、只有 1 人边走边打（散布 +3.5°），最多连退 2 次，之后强制 5s 不能再退。
- **入口**：**左侧**那扇门从第 10 关起专属敌军（常量 `SQUAD_GATE`，0=上 1=左 2=右，改一行就能换门），其余两扇只出普通敌人。没有小队的关卡，那扇门是关着的。
- **进场队形**：三人按「前二后一」的倒三角一起出现，整队沿进门方向往里 22px；多队时每队再往里错 46px。**不撒随机数**——以前在门口 ±26px 随机，会把三个人撒到墙外、散在门口。
- **登场**：第 10、15、20、25、30… 关（每 5 关一次），队数 `1 + floor((lv-10)/10)`：10/15 关 1 队、20/25 关 2 队、30/35 关 3 队。仅单人围城。
- **结算**：士兵被玩家击杀给 25 分；士兵击杀普通敌人**不给玩家分、不掉补给**。关卡清空要求场上所有敌对单位（含士兵）全部死亡。

### 5.5 相机（单人 / 快速围城）

```
tx = clamp(p.x - W/2, 0, max(0, mapW - W))
ty = clamp(p.y - H/2, 0, max(0, mapH - H))
remain = 冲刺中 ? 0.12 : 0.0000001
k = pow(remain, dt)
cam.x += (tx - cam.x) × (1 - k)
```

- 平时 `remain ≈ 0`，一帧内贴死玩家，玩家永远在屏幕中心
- 冲刺时 `remain = 0.12`，相机追不上，玩家会甩到画面前方约 50–90px，冲完瞬间归位——**这是冲刺唯一的"速度感"来源，不得删掉，也不得改成线性插值**
- 经典围城 `mapW = W`，`tx` 恒为 0，相机恒为 0，等于没有相机

### 5.6 安全屋地图构造

全部按视口比例生成，窗口怎么缩放都成立。`mw = 1.5W`，`mh = 1.5H`，墙厚 `T = 16`，门洞宽 `open = 96`，`midX = mw/2`，`midY = mh/2`。

┌──────────────┐  ← 上墙，中间是门洞

三条设计约束：

1. **所有掩体必须是凸矩形**。凹形（L 形、U 形）会在内角制造死路，距离场会把整片区域标成不可达

3. **门洞对齐屏风**，敌人进门必定被屏风挡一次，形成"先挨一刀再绕过来"的节奏

### 5.7 关卡进程（单人 / 快速围城）
