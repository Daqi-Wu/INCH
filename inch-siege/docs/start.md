# 方寸-围城 / INCH · SIEGE —— 设计与实现规格

> 方寸之内，退无可退。

本文档用于在另一个工作区从零复现《方寸-围城》。所有数值均为**建议实现值**，不是参考值——照抄即可得到一致手感。凡本文档未提及的视觉细节，以第 3 节 Design Token 为准，不得自由发挥。

**项目定位（2026-11）**：本项目只有一款作品——《围城》的波次射击，两个模式（经典围城 / 单人围城）。不再有合集入口，也没有其他待做作品：打开 `index.html` 直接进入围城的初始界面。此前试作过的九款储备（落差、悬廊、空巷、深井、断桥、哑火、尾灯、逆流、引信）连同代码与规格一并删除，只留下本文件里仍被《围城》用到的部分。

## 2. 技术形态（硬约束）

### 2.1 文件

- 单个 `.html`，内联 `<style>` 与 `<script>`
- 总大小建议 < 40KB
- 编码 UTF-8，`<meta charset="UTF-8">`
- 视口：`width=device-width, initial-scale=1.0`
- 只支持桌面浏览器（Chrome / Edge 最新版），**不做移动端适配、不做触屏**

### 2.2 画布

```js
DPR = Math.min(window.devicePixelRatio || 1, 2)
canvas.width  = Math.floor(W * DPR)
canvas.height = Math.floor(H * DPR)
canvas.style.width  = W + "px"
canvas.style.height = H + "px"
ctx.setTransform(DPR, 0, 0, DPR, 0, 0)
```

- `W = innerWidth`，`H = innerHeight`，每次 `resize` 重算并重新 `setTransform`
- `html, body { overflow: hidden; margin: 0; }`
- 游戏区域 = 整个视口，不存在"画布外"

### 2.3 主循环

```js
dt = Math.min((now - last) / 1000, 0.05)
```

- 单 `requestAnimationFrame` 循环，`dt` 上限 0.05s（切标签页回来不会瞬移）
- 所有运动以 `dt` 为单位（px/s、s/次），**不得写死每帧增量**
- 状态机：`"menu" | "playing" | "paused" | "over"`，单一枚举变量
- `paused` 与 `over` 状态下不执行 `update()`，但**继续执行 `render()`**

### 2.4 键位（本项目统一，不得改动）

| 键 | 作用 | 备注 |
|---|---|---|
| `WASD` / 方向键 | 移动 | 对角线速度需归一化 |
| 鼠标移动 | 瞄准 / 定位 | 无瞄准概念的游戏忽略此项 |
| 鼠标左键 | 主操作（射击 / 部署 / 确认） | 按下即触发，不等待抬起 |
| `Shift` | 冲刺（统一命名：冲刺） | 冷却 1.25s，持续 0.15s，期间无敌 |
| `Esc` | 暂停 / 继续 | 切换 `playing` ⇄ `paused` |
| `R` | 重开 | 仅在 `over` 状态有效 |
| 任意点击 / `Space` / `Enter` | 开始 | 仅在 `menu` 状态有效 |

- 全局 `cursor: none`，鼠标指针由 Canvas 绘制（见 3.6）
- `window.addEventListener("blur", ...)` 时清空按键表与鼠标按下状态，防止卡键
- 禁用 `Space`、方向键的默认滚动行为

## 4. 手感规范

### 4.1 打击感四件套

任何一次"命中"必须同时触发以下四项，缺一不可：

1. **白闪**——被击中对象 0.12s 变白
2. **击退**——给目标施加 0.012 倍弹道速度的位移冲量，随时间指数衰减
3. **火花**——命中点爆出 5 个同色系粒子，初速 150 左右
4. **微震**——`shake += 1.6`，上限 9（击杀时 `+= 4`，上限 14）

### 4.2 输入宽容

- **开火**：按下即发射，不等待抬起；冷却按固定间隔（射击类 0.105s）
- **跳跃**（空巷 / 逆流）：落地前 0.08s 内按跳记入缓冲；离开平台后 0.1s 内仍可跳（coyote time）
- **冲刺**：无敌帧覆盖整个 0.15s 位移过程，且冲刺中不受伤、不减速
- **暂停与重开**：从任何状态都能在 1 帧内响应，不等待动画结束

### 4.3 难度曲线通则

- 所有数值成长走**线性 + 轻微指数**，不得阶跃
- 每波敌人血量 `×(1 + (wave-1) × 0.17)`，速度 `×(1 + (wave-1) × 0.02)`
- 每波敌人数量 `4 + floor(wave × 2.2)`
- 波间间隔 2.0s；首波延迟 0.9s
- 场上敌人上限 46（性能与可玩性共同决定）

### 4.4 死亡与重开

- 死亡瞬间：60 颗红色粒子 + 20 颗白色粒子，`shake = 22`，立即切 `over` 状态
- 不播放死亡动画，不做慢动作，不做黑屏过渡
- 结算屏出现到可重开之间**无延迟**

## 5. 围城规格

俯视角。玩家在单屏内移动射击，敌人从四边涌入，波次无限。

**核心循环**：移动走位 → 瞄准射击 → 清空一波 → 更强的下一波

**参数**

| 对象 | 参数 |
|---|---|
| 玩家 | r=14，速度 265px/s，HP 100 |
| 冲刺 | 900px/s 持续 0.15s，冷却 1.25s |
| 子弹 | 速度 1020px/s，r=3.6，寿命 0.85s，伤害 26，射速 0.105s/发，散布 ±0.035rad |
| 追击兵 chaser | r=15，HP 30，速度 100，接触伤害 12，分值 10，色 `#ff5b5b` |
| 快速兵 fast | r=10，HP 16，速度 190，接触伤害 8，分值 15，色 `#ffd166`（第 3 波起） |
| 重装兵 tank | r=26，HP 130，速度 58，接触伤害 22，分值 30，色 `#a06bff`（第 4 波起） |
| 出生点 | 屏幕外 60px 的四边随机点 |
| 接触伤害 | 触发后玩家无敌 0.55s，敌人攻击冷却 0.7s，双方互相击退 320 |
| 回血道具 | 击杀时 13% 概率掉落，回复 28 HP，存活 13s |

**敌人 AI**：直线追击 + 正弦横向摆动（振幅系数 0.28）+ 同伴分离力。分离力按重叠深度 `×(r1+r2-d)×2.2` 计算，防止叠成一坨。

**失败**：HP ≤ 0

**得分**：累加击杀分值

**该作独有 UI**：冲刺冷却环（玩家外圈 r+8，从 12 点方向顺时针填充）、敌人头顶血条（仅受伤后显示，宽度 = 2r，高 4px）

## 6. 文件与版本约定

### 6.1 目录

```
inch-siege/
  index.html          围城本体：初始界面 + 游戏
  docs/
    start.md          本文件
    UI.md             视觉规范
```

- 一个项目 = 一个文件夹 = 一个 `index.html`。不再有合集入口，也不再有「储备」目录——不做就删掉，不留在仓库里占位
- 文件名一律小写、连字符分隔；项目文件夹以 `inch-` 前缀命名，后续若再开新作，与 `inch-siege/` 平级

### 6.2 代码组织

单文件内部按以下顺序分段，用注释分隔（**不写行内注释以外的文档**）：

```
1. 常量与色板
2. 工具函数（rand / clamp / dist2 / lerp）
3. 画布与 DPR 适配
4. 输入绑定
5. 游戏状态对象
6. 初始化 / reset()
7. 更新 update(dt)
8. 绘制 draw*()
9. 主循环
```

- 不使用 ES Module、不使用 `class`（保持 IIFE + 函数，方便直接复制）
- 所有可调数值集中在第 1 段，散落在逻辑里的魔法数字视为缺陷

### 6.3 版本

- 每个文件顶部 HTML 注释标注：`<!-- INCH · SIEGE / v1.0 -->`
- 未完成的功能不写 TODO，直接不做
