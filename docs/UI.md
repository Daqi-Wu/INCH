# INCH · 方寸 —— UI 规范

> 界面不解释，只显示。

本文档只管**看得见的东西**：画布、色板、排版、背景、实体绘制、HUD 组件、三屏幕版式、动效、可访问性。

玩法、关卡、数值平衡见 `start.md`。两份文档冲突时，**视觉以本文档为准，玩法以 `start.md` 为准**。

---

## 0. 三条原则

| #  | 原则              | 落地方式                                                   |
| -- | --------------- | ------------------------------------------------------ |
| U1 | **UI 永不进入画面中心** | 除准星与即时横幅外，所有 HUD 元素固定在屏幕四角 24px 安全边距内。中心 60% 的区域属于游戏本体 |
| U2 | **一个颜色只有一个意思**  | 青 = 你，红 = 会伤你，黄 = 快，紫 = 厚，绿 = 会帮你。全系列不得挪用              |
| U3 | **不用文字解释状态**    | 血量用条，弹药用格，进度用尺。数字只用于分数与倒计时两类真正需要精确值的量                  |

违反 U1 最典型的错误：把"波次 3/8"做成居中的大字常驻显示。正确做法是右上角 12px 副信息。

## 1. 画布与安全区

### 1.1 画布

游戏区域是**整个视口**，没有黑边、没有信箱模式、没有可滚动区域。

```css
html, body { margin: 0; padding: 0; width: 100%; height: 100%; overflow: hidden; }
canvas { display: block; }
body { cursor: none; }
```

`cursor: none` 必须全局生效——鼠标指针一律由 Canvas 绘制（见 7.9）。

### 1.2 安全边距

所有 HUD 元素距屏幕边缘至少 **24px**。理由：全屏时浏览器边缘的鼠标不可达区域会遮挡内容，且 24px 与卡片圆角 24px 呼应。

### 1.3 四角职责（不得互换）

```
┌──────────────────────────────────────────────────────────┐
│ ①资源条  244×14                       分数 01280   ②     │
│ HP 100 / 100                    WAVE 03   KILLS 12       │
│                                                          │
│                                                          │
│                      ✛  准星 ④                           │
│                                                          │
│                                                 速度/车损 │
│                                                    ③     │
└──────────────────────────────────────────────────────────┘
```

| 位置   | 职责          | 内容                                 |
| ---- | ----------- | ---------------------------------- |
| ① 左上 | **生存资源**    | 血条 / 弹药槽 / 车损格 / 深度尺 —— 回答"我还能撑多久" |
| ② 右上 | **成绩**      | 分数（大）、波次与击杀（小）—— 回答"我做得怎么样"        |
| ③ 右下 | **本作独有仪表**  | 速度表、车损、工具栏、双向条 —— 每款不同             |
| ④ 中心 | **操作指针对应物** | 准星，仅此一个                            |

**禁止**：底部中央放任何常驻元素（那是手机游戏的拇指区）；左侧放竖排菜单；顶部放进度条。

## 2. 色板

### 2.1 语义色（唯一允许的彩色）

| 语义    | Hex       | 内圈高光      | 允许出现的位置                  |
| ----- | --------- | --------- | ------------------------ |
| 玩家    | `#7ce7ff` | `#beeff7` | 玩家本体、冲刺拖尾、冲刺冷却环、准星、可交互提示 |
| 威胁·直接 | `#ff5b5b` | `#ff9b9b` | 追击型敌人、扣血、失败标题、危险警示条      |
| 威胁·快速 | `#ffd166` | `#fff0b8` | 高速型敌人                    |
| 威胁·重型 | `#a06bff` | `#d6c2ff` | 高血量敌人                    |
| 收益    | `#5df2a0` | `#a9ffd0` | 回血道具、正向反馈文字              |
| 弹体    | `#fff6cf` | —         | 子弹核心、枪口火焰、命中火花           |

**硬规则**

- 玩家色全系列恒为 `#7ce7ff`，**任何一款不得更换**
- 同屏彩色种类不超过 5 种（玩家 + 三类威胁 + 收益）
- 红色不用于装饰、不用于强调文字、不用于 Logo
- 紫与黄不得同时作为主色出现在同一款游戏的标题里

## 3. 排版

### 3.1 字族

```css
--font-body: "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
--font-mono: ui-monospace, Consolas, monospace;
```

| 用途              | 字族   | 说明                                  |
| --------------- | ---- | ----------------------------------- |
| 所有 HUD 数字、标题、按钮 | mono | **等宽是必须的**：分数从 9999 跳到 10000 时版面不能抖 |
| 长句操作提示          | mono | 与 HUD 同族，保持"机器感"                    |
| 无               | body | 本系列目前无长段落文本，body 字族仅作兜底             |

### 3.2 字号阶梯（只有这 8 级）

| 级  | 字号   | 字重  | 用途                         |
| -- | ---- | --- | -------------------------- |
| T1 | 62px | 800 | 菜单主标题                      |
| T2 | 52px | 800 | 波次横幅、结算"阵亡"（可用 56px）       |
| T3 | 30px | 700 | 结算得分                       |
| T4 | 26px | 700 | 右上分数                       |
| T5 | 16px | 600 | 按钮、可交互提示                   |
| T6 | 15px | 500 | 菜单操作提示行                    |
| T7 | 13px | 500 | 横幅副标题、标语                   |
| T8 | 12px | 500 | 次级信息（WAVE / KILLS / HP 说明） |

- 最小字号 11px，仅用于图表标注，正文不得使用
- 字重只用 400 / 500 / 600 / 700 / 800；**800 仅给 T1、T2**
- 中文标题字距 `letter-spacing: 0.12em`；英文与数字标题 `0.08em`
- 数字补零：分数固定 5 位（`01280`），波次固定 2 位（`03`）

### 3.3 对齐

- 左上资源条及其说明文字：`text-align: left`，基线对齐条底 +18px
- 右上分数与次级信息：`text-align: right`，右边缘严格对齐 `W-24`
- 三屏文案：全部 `text-align: center`，水平居中于 `W/2`
- **禁止**两端对齐、禁止混用左右对齐的居中元素

## 4. 背景

### 4.1 三层合成（顺序不可换）

```
① 径向渐变底
   圆心 (W/2, H/2)，内半径 60，外半径 max(W,H) × 0.78
   0%   #101728
   55%  #0a0e18
   100% #05070c

② 网格
   步长 64px，线宽 1px，颜色 rgba(90,130,190,0.075)
   所有坐标 Math.round(x) + 0.5，避免 1px 线糊成 2px

③ 暗角
   圆心 (W/2, H/2)，内半径 min(W,H) × 0.42，外半径 max(W,H) × 0.85
   0%   rgba(0,0,0,0)
   100% rgba(0,0,0,0.55)
```

暗角必须画在**实体之上、HUD 之下**。这样画面边缘的敌人仍可见（暗角只有 55%），但视线会被自然收拢到中心。

### 4.2 动态网格

八款共用同一张网格，靠**运动方式**区分身份。这是系列最省力的统一手段：

| 游戏 | 方向                   | 速度                  | 额外        |
| -- | -------------------- | ------------------- | --------- |
| 围城 | 水平 14px/s + 垂直 9px/s | 恒定                  | —         |
| 空巷 | 水平左移                 | = 玩家当前跑速            | —         |
| 深井 | 垂直下移                 | 200 → 900px/s，随深度递增 | —         |
| 断桥 | 静止                   | —                   | —         |
| 哑火 | 静止                   | —                   | α 提到 0.11 |
| 尾灯 | 垂直下移                 | = 车速                | 网格几乎被黑暗吞掉 |
| 逆流 | 水平左移                 | 恒定 180px/s          | —         |
| 引信 | 静止                   | —                   | α 降到 0.04 |

实现方式：不移动网格本身，而是让循环起点偏移。

```js
var step = 64;
var ox = (t * speedX) % step;
var oy = (t * speedY) % step;
for (var x = ox - step; x < W + step; x += step) { /* 竖线 */ }
for (var y = oy - step; y < H + step; y += step) { /* 横线 */ }
```

**禁止**：给网格加渐变、加辉光、加随机闪烁、加透视变形。

## 5. 实体绘制

### 5.1 五层模板（所有圆形实体必须按此顺序）

```
① 落地阴影   同色系暗圆，圆心 (x, y+4)，半径 r+2，rgba(0,0,0,0.42)
② 光环       半径 r+6，同色，alpha 0.14–0.16（仅玩家与可拾取物有）
③ 本体       径向渐变，内圈高光位于 (x - r*0.3, y - r*0.35)
④ 描边       2px，rgba(255,255,255,0.22)（玩家用 rgba(150,235,255,0.9)）
⑤ 细节       血条、朝向标记、弹道枪管等
```

可直接复制的通用函数：

```js
function entity(x, y, r, inner, outer, glowRgba) {
  ctx.beginPath();
  ctx.arc(x, y + 4, r + 2, 0, Math.PI * 2);
  ctx.fillStyle = "rgba(0,0,0,0.42)";
  ctx.fill();

  if (glowRgba) {
    ctx.beginPath();
    ctx.arc(x, y, r + 6, 0, Math.PI * 2);
    ctx.fillStyle = glowRgba;
    ctx.fill();
  }

  var g = ctx.createRadialGradient(x - r * 0.3, y - r * 0.35, 1, x, y, r + 1);
  g.addColorStop(0, inner);
  g.addColorStop(1, outer);
  ctx.beginPath();
  ctx.arc(x, y, r, 0, Math.PI * 2);
  ctx.fillStyle = g;
  ctx.fill();
  ctx.lineWidth = 2;
  ctx.strokeStyle = "rgba(255,255,255,0.22)";
  ctx.stroke();
}
```

### 5.2 尺寸

| 对象   | 半径  | 描边                          |
| ---- | --- | --------------------------- |
| 玩家   | 14  | 2px，`rgba(150,235,255,0.9)` |
| 小型敌人 | 10  | 2px                         |
| 中型敌人 | 15  | 2px                         |
| 大型敌人 | 26  | 2px                         |
| 子弹   | 3.6 | 无（实心）                       |
| 道具   | 11  | 无，外加 r+6 光环                 |

### 5.3 玩家

绘制顺序（**必须完全照做**，否则枪管会盖住朝向三角）：

```
1. 落地阴影
2. 以 aim 角旋转 → 枪管矩形（r-3 到 r+17，高 6.4）→ 复原
3. 枪口火焰（仅 muzzle > 0，半径 8 + progress*60，rgba(255,235,150,0.85)）
4. 本体渐变圆 + 描边
5. 以 aim 角旋转 → 朝向等腰三角（尖端在 r-1，底边在 r-9，高 ±5）→ 复原
6. 冲刺冷却环（仅 dashCd > 0）：半径 r+8，2.5px，从 12 点方向顺时针，
   rgba(124,231,255,0.5)，进度 = 1 - dashCd/1.25
```

无敌帧表现：**不做整体闪烁**（会造成视觉疲劳），而是把本体 alpha 降到 0.35，其余部分不变。

### 5.4 敌人

- 血条仅在 `hp < maxHp` 时显示，位于 `(-r, -r-9)`，宽 2r，高 4px
- 血条底槽 `rgba(0,0,0,0.55)`，填充 `#ff5b5b`，**不描边**
- 受击 0.12s 内本体填充替换为 `#ffffff`，其余层不变
- 大型敌人在血条外增加 1px 深色轮廓，提高在暗背景上的可辨识度

### 5.5 道具

```
底：r+6 光环，同色 alpha 0.14
体：实心圆 r=11
符号：十字（两条 3.6 宽矩形），颜色为深色底 rgba(6,30,18,0.9)
动效：上下浮动 sin(t*4)*3
```

## 6. HUD 组件库

所有组件以屏幕左上角为原点计算，`W`、`H` 为视口尺寸。下列数值**直接可用**。

### 6.1 资源条（血条 / 通用进度）

| 项    | 值                                                               |
| ---- | --------------------------------------------------------------- |
| 位置   | `(24, 24)`                                                      |
| 尺寸   | `244 × 14`                                                      |
| 底槽   | `rgba(255,255,255,0.09)`                                        |
| 填充   | 比例 > 0.35：`#2ee6a8 → #8ff7d0`；≤ 0.35：`#ff3b3b → #ff9b6b`（左→右线性） |
| 描边   | 1px `rgba(255,255,255,0.18)`，`strokeRect(x+0.5, y+0.5, w, h)`   |
| 说明文字 | `(24, 62)`，12px/500 mono，`text-align: left`，内容 `HP 100 / 100`   |

```js
function bar(x, y, w, h, ratio) {
  ctx.fillStyle = "rgba(255,255,255,0.09)";
  ctx.fillRect(x, y, w, h);
  var g = ctx.createLinearGradient(x, 0, x + w, 0);
  if (ratio > 0.35) { g.addColorStop(0, "#2ee6a8"); g.addColorStop(1, "#8ff7d0"); }
  else { g.addColorStop(0, "#ff3b3b"); g.addColorStop(1, "#ff9b6b"); }
  ctx.fillStyle = g;
  ctx.fillRect(x, y, w * Math.max(0, Math.min(1, ratio)), h);
  ctx.strokeStyle = "rgba(255,255,255,0.18)";
  ctx.lineWidth = 1;
  ctx.strokeRect(x + 0.5, y + 0.5, w, h);
}
```

### 6.2 弹药槽（哑火专用）

替代 6.1 的位置与尺寸。

- 每发弹 = 一个 `36 × 8` 短横，间距 10px，起始 `(24, 27)`
- 有弹：实心 `#7ce7ff`
- 无弹：仅 1px 描边 `rgba(124,231,255,0.35)`，无填充
- 拾取瞬间该格放大到 `1.25` 倍并在 0.15s 内回落
- 说明文字 `(24, 62)`：`AMMO 4 / 6`

### 6.3 格状计数（尾灯车损）

- 3 个 `24 × 14` 方块，间距 8px，起始 `(24, 27)`
- 完好：`#7ce7ff` 实心
- 损坏：只剩 1px 描边 `rgba(255,91,91,0.5)`，内部为 `rgba(255,91,91,0.12)`
- 说明文字：`HULL 2 / 3`

### 6.4 竖尺（深井深度）

- 位于右侧，`x = W - 68`，`y` 从 `80` 到 `H - 80`
- 主轴线 1px `rgba(124,231,255,0.18)`
- 刻度：每 100m 一条 12px 横线 + 右侧 11px 数字（`rgba(180,205,230,0.7)`）
- 当前位置：青色短横 12×3，位于轴线上，`#7ce7ff`

### 6.5 双向条（逆流）

- 位置：`x = W/2 - 160`，`y = H - 28`，尺寸 `320 × 6`
- 中点零位：2px 竖线，`rgba(255,255,255,0.35)`
- 向右（净前进）：`#7ce7ff`，从中心向右填充
- 向左（被推回）：`#ff5b5b`，从中心向左填充
- 满量程 = 600px 位移

### 6.6 墙距条（空巷）

- 位置：`x = W/2 - 160`，`y = 24`，尺寸 `320 × 6`
- 填充从中心向两侧延伸的比例 = `墙距 / 200`
- 距离充足：`#eaf6ff`；距离 < 60px 时转 `#ff5b5b` 并以 12Hz 闪烁

### 6.7 工具栏（断桥）

- 位置：底部居中，`y = H - 96`
- 三个 `56 × 56` 方格，间距 12px，圆角 8
- 未选中：填 `rgba(255,255,255,0.09)`，1px 描边 `rgba(255,255,255,0.18)`
- 选中：描边变 `#7ce7ff`，2px，内部叠加 `rgba(124,231,255,0.12)`
- 买不起：整体 alpha 0.35
- 价格：格子右下角 11px/500 mono
- 零件数：工具栏右侧 20px 处，26px/700 mono，`#7ce7ff`

### 6.8 引信条（引信）

- 尺寸 `420 × 26`，水平居中，垂直均匀分布于 `H*0.2` 到 `H*0.8`
- 底槽 `rgba(255,255,255,0.09)`
- 剩余量填充：> 25% 为 `#ffd166`，≤ 25% 为 `#ff5b5b`
- 键名：条内左侧 16px 处，14px/700 mono，`#eaf6ff`
- 末端火星：每帧 2 个粒子，向上飘 0.4s，色 `#ffd166`
- ≤ 25% 时整条以 1px 幅度抖动，频率 18Hz

### 6.9 准星

```
圆心 (mouse.x, mouse.y)
外圆 r=9，1.6px 描边 rgba(140,235,255,0.9)
四条刻线：从 r=6 到 r=16，上下左右各一
中心实心方块 3×3，同色
```

- **必须每帧跟随鼠标**，不得有缓动延迟
- 悬停在可交互对象上时，外圆半径放大到 12（唯一允许的准星状态变化）
- 不含瞄准概念的游戏（空巷、断桥、引信）不绘制准星，但 `cursor: none` 仍然生效

### 6.10 波次横幅

- 位置 `(W/2, H*0.24)`，居中
- 主行：52px/800 mono，`#eaf6ff`，内容 `第 03 波`
- 副行：13px/500 mono，`rgba(150,200,235,0.85)`，位于主行下方 26px，内容 `ENEMIES INCOMING`
- 存活 1.6s，`alpha = min(1, bannerTime / 0.4)`
- **不做位移动画**，只做透明度淡出

## 7. 三屏版式

三屏共用遮罩层，但透明度不同：

| 屏  | 遮罩                  | 说明                   |
| -- | ------------------- | -------------------- |
| 菜单 | `rgba(5,8,14,0.78)` | 背景网格仍需可见，让人先看到"活的画面" |
| 暂停 | `rgba(5,8,14,0.70)` | 比菜单更透，强调"游戏还在那儿"     |
| 结算 | `rgba(10,4,6,0.82)` | 偏红，与死亡情绪一致           |

### 7.1 菜单

| 元素   | 位置                | 规格                                                                 |
| ---- | ----------------- | ------------------------------------------------------------------ |
| 游戏名  | `(W/2, H/2 - 60)` | 62px/800 mono，`#eef8ff`，字距 0.12em                                  |
| 操作提示 | `(W/2, H/2 - 14)` | 15px/500 mono，`rgba(160,205,240,0.85)`                             |
| 开始提示 | `(W/2, H/2 + 44)` | 16px/600 mono，`rgba(140,235,255,0.95)`，呼吸 `0.55 + sin(t/320)*0.45` |

操作提示行格式固定：`动作 按键 · 动作 按键 · …`，覆盖该款**全部**操作，一行写完不换行。

## 8. 动效

### 8.1 时长阶梯（只有这 6 档）

| 时长 | 用途 |
|---|---|
| 0.07s | 枪口火焰 |
| 0.12s | 命中白闪 |
| 0.15s | 冲刺持续、弹药槽放大回落 |
| 0.45s | 滑铲、拾取反馈 |
| 0.60s | 受击红边衰减 |
| 1.60s | 横幅淡出 |

**禁止**：缓动函数（`ease-in-out`、`cubic-bezier`）。所有过渡均为线性或指数衰减 `Math.pow(k, dt)`。街机手感来自"快起快落"，曲线缓动会让它变软。

## 9. 可访问性

系列追求克制的美术，已经天然规避了大部分问题，但以下四条必须遵守：

| 项 | 要求 |
|---|---|
| 对比度 | 文本与背景对比 ≥ 4.5:1。`#eaf6ff` 对 `#05070c` 为 16:1，安全；`rgba(180,205,230,0.7)` 对背景约 6:1，达标 |
| 不只靠颜色 | 敌人除颜色外必须有**尺寸差异**（10 / 15 / 26 三档），色盲用户靠大小区分 |
| 红绿不并置 | `#ff5b5b` 与 `#5df2a0` 不得紧邻出现（血条填充渐变已避开这一组合） |
| 闪烁频率 | 任何闪烁 ≤ 12Hz；全屏红闪为一次性衰减，不循环 |

## 10. 反例（出现即视为缺陷）

1. 用 `shadowBlur` 做辉光 —— 性能不可控，改用 r+6 半透明垫圆
2. 血条做成圆角/异形 —— 必须直角矩形
3. HUD 加投影或描边文字 —— 只用纯色填充
4. 分数用 body 字族 —— 变宽数字会导致版面抖动
5. 按钮做成有背景色的矩形块 —— 本系列按钮即文字，靠呼吸透明度提示可点
6. 菜单放 Logo 图标或副标题 —— 只有三行：名字、操作、开始
7. 结算屏加"再来一次"以外的任何按钮
8. 用 `ease` 缓动做淡入
9. 给背景加噪点、扫描线、CRT 滤镜
10. 在画面中心常驻显示波次数或倒计时
